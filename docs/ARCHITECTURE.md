# هندسة مشروع مِعيار

## المبدأ

المشروع واجهة static، لا يحتاج خادمًا لتشغيل الواجهة. تُقدَّم ملفات HTML/CSS/JS مباشرة، بينما مزامنة البيانات تتم مع Google Apps Script وGoogle Sheets. لذلك يجب الفصل بين ملفات الواجهة والاختبارات والتوثيق وكود التكامل الخارجي.

## المسؤوليات الحالية

| المسار | المسؤولية |
| --- | --- |
| `index.html` | نقطة الدخول، metadata وروابط ملفات الواجهة |
| `css/style.css` | الثيمات والتصميم المتجاوب ومكونات الواجهة |
| `js/app.js` | حالة التطبيق، الحسابات، العروض، الأحداث والتكامل مع Google Apps Script |
| `assets/` | شعارات وصور العلامة التجارية |
| `site.webmanifest` و`favicon.svg` | بيانات تثبيت الموقع وأيقونته |
| `tests/` | اختبارات الانحدار للحسابات ووجود عناصر الواجهة |
| `docs/` | شرح التشغيل والمزامنة وكود Google Apps Script |
| `.github/workflows/` | فحوص تلقائية قبل الدمج |
| `Meyaar-main/Meyar/index.html` | تحويل توافق فقط للرابط القديم؛ لا تضع ميزات جديدة هنا |

## مسار البيانات

1. تُدخل المعاملات من الواجهة.
2. يُطبّق منطق التحقق والحساب داخل JavaScript.
3. تُرسل البيانات المشتركة إلى Google Apps Script الذي يتعامل مع Google Sheets.
4. يتم تحميل المعاملات والإعدادات المشتركة عند فتح الصفحة وأثناء المزامنة.
5. الاختبارات تتحقق من الحسابات وقواعد الأعمال الأساسية؛ ولا تحل محل اختبارات المتصفح الفعلية أو فحص صلاحيات نشر Apps Script.

## قواعد التطوير

- اعتبر معاملات Google Sheets والرصيد المحسوب بيانات حساسة؛ لا تغيّرها ضمن إعادة تنظيم ملفات أو تحسين بصري.
- احتفظ بمخطط الأعمدة الحالي A:L إلى أن يُصمّم إصدار ترحيل واختبارات له.
- افصل الإصلاح المالي عن التغيير الشكلي في pull request قدر الإمكان.
- أي ميزة جديدة يجب أن تضيف اختبارات للحالات الطبيعية والحدّية والفشل.
- حدّث توثيق `docs/` في نفس التغيير الذي يعدّل طريقة التشغيل أو مزامنة البيانات.

## خارطة طريق آمنة لتقسيم الملف الكبير

لا يتم تقسيم `js/app.js` آليًا أو نقل الدوال عشوائيًا، لأن أجزاءه تعتمد على حالة مشتركة وترتيب التهيئة. بعد توسيع الاختبارات، يمكن فصل المكونات بالتدريج إلى وحدات منطقية مثل:

- `js/core/`: قواعد الحساب والتحقق والتواريخ والعملات.
- `js/data/`: التخزين المحلي والمزامنة وواجهة Google Apps Script.
- `js/features/`: المعاملات، الحسابات، الالتزامات، الأهداف، مصادر الدخل والأصول.
- `js/ui/`: التنقل والمكونات المشتركة والرسم البياني.

يُنفّذ كل فصل في تغيير مستقل، مع إبقاء مخرجات الحسابات ومخطط البيانات كما هي.
