# مِعيار — مزامنة الأجهزة

## البيانات المشتركة

- المعاملات محفوظة في DB_TRANSACTIONS بالأعمدة A:L.
- الحسابات والأرصدة الافتتاحية، أسعار الأصول، أسعار الصرف وسجلها، الميزانية وحد التحذير، الالتزامات، الأهداف المالية، ومصادر الدخل تُحفظ في SYS_APP_SETTINGS مستقلة عن شيت المعاملات.
- الفلاتر والثيم والقسم المفتوح يظل كل منها محليًا على الجهاز.
- الموقع يحمّل المعاملات والإعدادات من Google عند الفتح، ويحدّث البيانات دوريًا كل 45 ثانية أثناء بقاء الصفحة ظاهرة.
- الإعدادات لا تُرفع تلقائيًا قبل معرفة الحالة السحابية، حتى لا تستبدل الإعدادات الافتراضية لجهاز جديد الإعدادات الصحيحة الموجودة.

## التفعيل

1. احتفظ بنسخة من كود Apps Script الحالي.
2. انسخ الكود من [apps-script/Code.gs](../apps-script/Code.gs) إلى Code.gs في مشروع Apps Script المرتبط بالشيت.
3. من Deploy → Manage deployments عدّل نشر Web App الحالي واختر New version → Deploy. يجب أن يظل API_URL في الواجهة يشير إلى عنوان النشر الصحيح.
4. افتح الموقع على الجهاز الذي يحمل الإعدادات الصحيحة، ثم الإعدادات → مزامنة الأجهزة → مزامنة إعدادات هذا الجهاز مرة واحدة.
5. افتح نفس رابط GitHub Pages على الهاتف. ستتزامن البيانات المشتركة تلقائيًا عند الفتح وأثناء بقاء الصفحة ظاهرة.

## حماية المعاملات

- المزامنة المشتركة لا تكتب في DB_TRANSACTIONS؛ إعدادات الموقع لها ورقة منفصلة SYS_APP_SETTINGS.
- لم تتغير أعمدة المعاملات أو طريقة حفظها وقراءتها.
- إذا اكتشف Apps Script بنية غير متوقعة داخل SYS_APP_SETTINGS فسيتوقف بدلًا من مسحها أو إعادة تنسيقها.
- عند تعارض تعديلين في سجلات مختلفة، يحافظ الدمج على الاثنين. إذا عدّل جهازان السجل نفسه، فآخر حفظ ناجح لذلك السجل هو الذي يبقى.
- اختبر مزامنة الإعدادات بمصدر دخل مؤقت أو إعداد غير مالي. لا تستخدم معاملة مالية وهمية في شيت الإنتاج للاختبار.

## ملاحظة مهمة

نشر تحديث الواجهة في GitHub وحده لا يحدّث كود Google Apps Script الخارجي. يجب نشر نسخة جديدة من Apps Script كي تتفعّل مزامنة الإعدادات.
