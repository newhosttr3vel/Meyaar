# مِعيار | Meyaar

تطبيق ويب لإدارة الأموال الشخصية، مبني حاليًا باستخدام HTML وCSS وJavaScript عادي، ويُقدَّم من خلال GitHub Pages. يتصل التطبيق بواجهة Google Apps Script لحفظ المعاملات والإعدادات المشتركة في Google Sheets.

## البداية السريعة

- **تشغيل الموقع:** افتح `index.html` محليًا أو استخدم [نسخة GitHub Pages](https://newhosttr3vel.github.io/Meyaar/).
- **فحص صياغة JavaScript والاختبارات:** يتطلب Node.js 20 أو أحدث، ثم شغّل `npm run validate`.
- **كود Google Apps Script:** يوجد في `docs/GOOGLE_APPS_SCRIPT.md`.
- **ملاحظات مزامنة الأجهزة:** راجع `docs/README_AR.md`.

لا يحتاج التطبيق إلى خادم Node.js للتشغيل؛ Node.js مستخدم للاختبارات فقط.

## قواعد مهمة قبل التطوير

1. لا تغيّر شكل بيانات المعاملات في Google Sheets أو ترتيب الأعمدة A:L دون خطة ترحيل واختبارات توافق.
2. تغيير الواجهة يجب أن يبقى منفصلًا عن منطق الحسابات وتخزين المعاملات.
3. أضف اختبارًا لكل إصلاح مالي أو سلوك جديد، ولا تعتبر نجاح فحص الصياغة وحده دليلًا على صحة الحسابات.
4. لا تضع مفاتيح أو أسرارًا في ملفات الواجهة الثابتة. صلاحيات البيانات تعتمد أيضًا على إعدادات نشر Google Apps Script.
5. مسار الموقع القديم `Meyaar-main/Meyar/` محفوظ كتحويل للرابط الرئيسي حتى لا تتعطل الروابط القديمة.

## ملاحظة عن تنظيم JavaScript

الملف `js/app.js` ما زال يحتوي معظم منطق التطبيق في ملف واحد. تم توحيد مسار التشغيل أولًا من دون إعادة تقسيم المنطق المحاسبي؛ فصل الحسابات والمعاملات والأهداف والالتزامات إلى وحدات مستقلة سيكون مرحلة لاحقة، بعد تجهيز اختبارات أوسع لضمان عدم تغيير النتائج.
